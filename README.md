# BIST Pusula

Borsa İstanbul için kişisel gün içi işlem terminali.

- `index.html` — terminalin tamamı (GitHub Pages'ten yayınlanır, ana ekrana uygulama olarak eklenir).
- `worker/` — Cloudflare sunucusu (canlı veri, sinyal karnesi, KAP, Telegram).
- `pc/` — iş bilgisayarındaki sinyal motoru.
- `tests/` — testler: `bash tests/run.sh`
- `tools/` — araştırma betikleri.
- `docs/DEVIR.md` ve `CLAUDE.md` — geçmiş, kararlar ve çalışma notları.
